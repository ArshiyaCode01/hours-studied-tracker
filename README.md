# Hours Studied Tracker

## Project Goal
A lightweight web application built to help college students track, manage, and analyze their study hours across different courses to optimize productivity.

## MVP Scope (Urgent & Important)
- Manual time entry (Subject name, duration, date, and notes).
- CRUD functionality (Create, Read, Update, Delete study logs).
- Dashboard view displaying total hours studied.

## Future Plans (Schedule Quadrant)
- Data visualization graphs showing weekly study trends.
- Weekly study goal setting and streak tracking.

## Tech Stack
- **Backend:** Python (Flask)
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript
