# Hours Studied Tracker

## Project Goal
A lightweight web application built to help college students track, manage, and analyze their study hours across different courses to optimize productivity.

## MVP Scope (Urgent & Important)
- Manual time entry (Subject name, duration, date, and notes).
- CRUD functionality (Create, Read, Update, Delete study logs).
- Dashboard view displaying total hours studied.

## Future Plans (Schedule Quadrant)
- Data visualization graphs showing weekly study trends.
- Weekly study goal setting and streak tracking.

## Tech Stack
- **Backend:** Python (Flask)
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript

## Setup & Installation (Fresh Terminal)
Follow these steps to run the application locally:

1. **Clone the repository and enter the directory:**
   ```bash
     git clone [https://github.com/ArshiyaCode01/hours-studied-tracker.git](https://github.com/ArshiyaCode01/hours-studied tracker.git)
    cd hours-studied-tracker
2. **Create and activate a Python virtual environment:**
    python -m venv venv
    venv\Scripts\activate
3. **Install required dependancies:**
    pip install -r requirements.txt
4. **Run the application:**
     python3 app.py
5. **Open in Browser:**
     Navigate to http://127.0.0.1:5000 in your web browser.
